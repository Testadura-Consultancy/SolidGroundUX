Use themed colors, styles, and glyphs
sux_epilogue.sh::How do I...?:Use themed colors, styles, and glyphs:

Use the framework UI variables instead of hard-coded terminal escape sequences. Color and style variables keep framework UI primitives consistent across themes, while glyph variables provide reusable symbols for status, navigation, prompts, and visual markers.

Program-generated messages should still go through the SolidGroundUX output primitives rather than being printed directly. For example:

sayok "Operation completed"
sayinfo "Validated"

Use theme/color/glyph variables directly when implementing a UI primitive or the immediate mechanics of a prompt/input interaction. They are not a reason to bypass `say*`, `sgnd_print*`, or the shared dialog helpers for ordinary application output.
