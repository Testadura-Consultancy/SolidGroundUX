Publish generated documentation to the configured Git output path
SolidGroundUX Codex / doc-generator.sh / Local script functions / _copy_docs_to_git
Purpose
Publish the generated documentation tree to a user-selectable Git-facing directory.
Behavior
- Uses VAL_GIT_OUTPUT_PATH when configured.
- Falls back to <primary-repo-root>/docs for compatibility when no path is stored.
- Stages a complete copy of the freshly rendered site beside the destination.
- Replaces the previous published tree only after the staged copy succeeds.
- Restores the previous published tree if final replacement fails.
- Does nothing when FLAG_COPY_TO_GIT is disabled.
Returns
0 when publishing is disabled or completes successfully.
1 when the destination or generated site cannot be resolved safely.
Usage
_copy_docs_to_git
