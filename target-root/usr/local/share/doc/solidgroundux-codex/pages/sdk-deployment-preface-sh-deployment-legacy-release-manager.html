Legacy Release Manager
sdk-deployment_preface.sh::Deployment:Legacy Release Manager:

`release-manager.sh` is the predecessor of Setup. It remains relevant to installations created before the Setup transition and can provide the one-time bridge into the new lifecycle model.

New installation and lifecycle documentation should use `sgnd-setup`. Maintaining both tools as equal, parallel entry points would make the documentation and operator model needlessly ambiguous.
