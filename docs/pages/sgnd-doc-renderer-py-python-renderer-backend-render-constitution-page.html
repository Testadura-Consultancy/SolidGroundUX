Purpose
Render CONSTITUTION.md as product front matter immediately beneath the product landing
page. Constitution is deliberately outside the appendix sequence. Historical canonical
filenames remain compatibility fallbacks for repositories not yet renamed.
Arguments
product_name Product whose Constitution document should be rendered.
Usage
self.render_constitution_page(<product_name>)
