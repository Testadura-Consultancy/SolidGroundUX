fn: sgnd_dt_column_count

Purpose

Count the columns in a pipe-delimited schema.

Arguments

  • $1 — Schema string.

Output

Writes the count to stdout.

Returns

  • 0 after writing the column count.

Usage

  sgnd_dt_column_count "name|role"
